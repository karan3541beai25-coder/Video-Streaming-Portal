ABOUT US

Welcome to LocoFlix

LocoFlix is a college project based on the concept of a modern video streaming platform.

Our objective is to create an attractive, responsive and user-friendly platform where users can discover movies and entertainment.

The first version of this project focuses on HTML, CSS and basic JavaScript. Future versions can include React, databases, APIs and complete authentication.
